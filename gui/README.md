# GestureChatBot
Robot (MS-Rabot) ChatBot with Gesture since 2022 mainly develped by Teshima


## face detection
use face detector by opencv(https://github.com/opencv/opencv/blob/master/data/haarcascades/haarcascade_frontalface_default.xml). [based face_detect.py]

## mic record
use pyaudio(https://pypi.org/project/PyAudio/) to record voice as .wav file.[based mic_cap.py]

## GUI
strat overall GUI[GUI.py].
UI design[communication_robot_001.py] created by Qt creator.
